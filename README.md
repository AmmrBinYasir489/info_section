## **Experiment 1: Study of Network Cables & Making Straight-Through Cable**

**Objective:**
Different types of network cables ka study karna aur straight-through cable banana.

**Theory:**
Network cables computers aur network devices ko connect karne ke liye use hoti hain.

**Types of Network Cables:**

* **Twisted Pair Cable (UTP/STP)** – LAN mein common
* **Coaxial Cable** – Cable TV
* **Fiber Optic Cable** – High speed, long distance

**Straight-Through Cable:**
Is cable mein dono ends par **same color sequence (T568A ya T568B)** hoti hai.
Mostly **PC to Switch** connection ke liye use hoti hai.

**Tool Used:**

* Clamping / Crimping Tool
* RJ-45 Connector
